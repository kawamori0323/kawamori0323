## 🚀 Memo-z（マルチリポジトリ型 どこでも使えるクラウドメモアプリ）
Webブラウザから利用できるクラウドメモアプリ。ログイン後にリッチテキスト形式でメモを作成・管理でき、スマートフォン、タブレット、PCを問わず利用可能。  
既存のメモアプリでは実現したい操作やカスタマイズ性に不足を感じたため、技術習得を兼ねて開発した。  
今後の拡張として、スプレッドシートの形をしたメモや、同一メモのリアルタイム共有編集を検討中。  

| 項目 | 内容 |
| :--- | :--- |
| **システム構成** | マルチリポジトリ構成（Base環境基盤 / Goバックエンド / Reactフロントエンド） |
| **バックエンド** | **Go**, **Gin**, **Clean Architecture**（Domain / Usecase / Handler / Adapter / Middleware） |
| **フロントエンド** | **TypeScript**, **React**, **Next.js(AppRouter)**（主にトークン認証管理）, **Tiptap**（リッチテキストエディタ） |
| **認証・認可** | **Amazon Cognito**（User Pools / JWTトークン検証・認可） |
| **クラウド・DB** | **AWS**（Lambda Function URL, DynamoDB） |
| **IaC・開発基盤** | **Terraform** (インフラ完全コード化), **mise**, **GitHub Codespaces**, Dev Containers |

### 設計・実装のこだわりとアピールポイント
- **Go言語によるクリーンアーキテクチャ設計**
  - `domain`, `usecase`, `handler`, `infrastructure` などに厳密にレイヤーを分離し、テスタビリティと疎結合性を追求。
- **AWSサーバーレス × Terraform による完全IaC化**
  - Go（Lambda Function URL）+ DynamoDBを採用し、スケーラビリティと運用コストを考慮した構成。LambdaやDynamoDB等、全AWSリソースはterraformで管理し、デプロイまでterraform applyで実施可能。
  - 単一のスクリプト実行で、Terraformによるインフラ構築からビルド・リリースまで完了するCI/CD環境を整備。
- **AppRouterとCognitoによるセキュアなJWT認証・認可ミドルウェア**
  - AppRouterサーバーコンポーネント側で全ての環境変数及びトークンを扱うことで、クライアントに不要な情報を見せないセキュアなアプリケーションを構築。
  - Goバックエンドを通してCognitoの検証・認可制御を実施することで、堅牢なセキュリティと高い運用効率を両立。
- フロントエンドのリリースも自動化
  - 単にVercelを本番リリース用に利用しているだけだが、それにより複雑な設定不要でリリースでき、さらにコミットを検知してデプロイする仕組みが構築済み。
- **Dev Containers + mise による統一開発環境**
  - CodespacesとDev Containersにmiseを組み合わせ、Codespaces環境作成と同時に開発環境の構築・初期化が完了する再現性の高いBase環境基盤を構築。
  - 認証関連の秘密情報はCodespaces Secretsで管理し、初期化時に環境変数に注入するなど、セキュアかつ作業コストを抑えた環境構成の実現。

## 🔧 Goツール色々
- 画像ファイルをロスレスカットなど最適化と、AVIF化などディレクトリ単位で一括で実施してzip圧縮するツール  
- 動画のサイズ変更や最適化をディレクトリ単位で一括実施するツール  
- Youtubeの動画を簡単な条件指定で複数DLするツール  
- 画面表示を判断して適切な操作を入力するマクロ自動操作ツール
- Kindleなどの電子ブックを一枚ずつキャプチャして画像でどこでも見れるようにするツール

その他必要に応じたツールをGoでビルドして、バイナリでどこでも実行できる形にして利用している
