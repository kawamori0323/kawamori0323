# WSLの初期化用のスクリプトを配置するための場所
必要最小限の構成とする。


基本的には、mise などインストールするだけ。
その後、目的ごとに必要な環境変数を対話入力する。 .bashrc.local に書き込み。

最後に環境変数にした秘密情報を使って、各種リポジトリをcloneして
それぞれ内部のmiseスクリプトで初期化実施を想定。


## その後の顛末
秘密情報の扱いで、スマートな着地が出来なかったので一旦保留。  

正直プライベート開発では、CodeSpacesならオールインワンでシンプルに構築できるので
それを捨てて複雑にいろいろなサービスを組み合わせてまでWSL利用にこだわるメリットがない。

動画や画像の最適化環境を構築する目的もあり、不要とまでは言わないが
ローカルツールでは秘密情報は原則不要なので、ひとまずは手動での環境構築を手順化したほうが運用コストもかからない。
